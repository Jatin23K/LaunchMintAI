Search Engine Pipeline
3-tier waterfall: Exa semantic → Serper Google → Gemini training data fallback + 24h cache
9 Checkpoints
🧠Tier 0 — Exa Semantic
  • Neural search — understands meaning not keywords
  • Targets: Statista, Gartner, Mordor, Fortune BI
  • Returns: title, URL, text snippet, published date
  • Max results: 8 per query
  • Timeout: 10s per key attempt
  • On zero results → fall to Tier 1
🔎Tier 1 — Serper Google
  • REST call to Google via Serper API
  • Query format: "market size report [idea]"
  • Returns: organic results + knowledge graph
  • Max results: 10 per query
  • Deduplication by URL before merging
  • On zero results → fall to Tier 2
💡Tier 2 — Gemini Fallback
  • Uses Gemini training knowledge directly
  • Confidence flagged as "Medium"
  • No live data — hallucination risk present
  • Prompt includes caveat to indicate training data
  • Result still cached to prevent repeat calls
💾Cache System
  • Key = MD5(normalized query string)
  • TTL = 24 hours per entry
  • Storage = in-memory Python dict
  • On cache hit → skip all API calls
  • Cache cleared on server restart
  • No persistent disk cache (by design)

LLM Engine Validation
Model selection logic, key rotation, retry behaviour, JSON parsing, fallback chain
12 Checkpoints
🔄Key Rotation
  • Global atomic counter per provider
  • Modulo key count → even distribution
  • _next_gemini_offset() function
  • _next_nim_offset() function
  • No stickiness — each call picks next key
  • Validated at startup: print key counts
⚙️Model Waterfall
  • Attempt 1: gemini-2.5-flash (key offset N)
  • On 429/503: increment offset, retry
  • Attempt 2: gemini-2.5-flash-lite
  • Attempt 3: NIM llama-3.1-70b
  • Max retries: 3 per call
  • Final fallback: return error JSON
📋JSON Parsing Safety
  • Strip markdown fences (```json … ```)
  • Strip leading "json" after fence open
  • json.loads(result.strip())
  • On parse failure: return {"error","raw"}
  • Frontend checks for .error field
  • Never throws — always returns dict

Error Handling Validation
Every failure mode — what happens when APIs fail, JSON breaks, network drops
6 Scenarios
🌐Network / API Failures
  • Gemini 429: auto-rotate to next key
  • NIM timeout: fallback to Gemini
  • Exa 0 results: fall to Serper tier
  • Serper 0 results: fall to Gemini training
  • Frontend timeout (180s): show retry prompt
  • CanceledError / AbortError: show specific message
📋JSON Parse Errors
  • All extensions: try/except around json.loads
  • On fail: return {"error","raw"}
  • Frontend checks .error key before render
  • Markdown fence stripping before parse
  • Partial section failure: show other sections
  • Never crashes entire response
💥Backend Startup Errors
  • SyntaxError in any extension: server won't start
  • Import failure: logged as REAL error (no try/except)
  • Missing key: pool degrades gracefully
  • Extension not found: 404 with clear message
  • Startup print: "[OK] IMPORTS SUCCESSFUL"
  • Request logging middleware for all POSTs
